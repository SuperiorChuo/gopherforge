# WeChat Official Accounts

The **mp service** covers official-account operations: accounts, followers, menus, media, broadcasts and callbacks.

## Capabilities

- **Accounts**: multi-account onboarding (AppID / AppSecret / Token / message crypto key); credentials are **encrypted at rest and masked in every API and log**.
- **Followers & segments**: follower lists, tag segments, blacklists.
- **Menus & media**: custom menus and media material management.
- **Messaging & broadcasts**: template / customer-service messages, segment broadcasts, delivery records.
- **Callbacks**: message and event callbacks with signature verification.

## Boundaries

- 🧪 Experimental line: APIs and schemas may still change.
- Account qualification, API access and quotas are governed by the WeChat platform, not by this repository.
