# Tickets

The **ticket service** manages the full ticket lifecycle: creation, assignment, resolution and SLA tracking.

## Capabilities

- **Tickets**: create / assign / transition / close with title, priority, source and linked business objects.
- **SLA**: response / resolution targets with overdue marking.
- **Event stream**: every state change, note and action is recorded (events).
- **Statistics**: ticket rollups by status / owner / period and dashboard views.
- **Data scopes**: self / department / all, tenant-isolated.
