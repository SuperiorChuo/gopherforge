# 公众号运营

**mp 服务**面向微信公众号运营：账号管理、粉丝、菜单、素材与群发、回调处理。

## 能力清单

- **账号管理**：多公众号接入（AppID / AppSecret / Token / 消息加解密密钥），凭据**加密存储、接口与日志一律脱敏**。
- **粉丝与分组**：粉丝列表、标签分组、黑名单。
- **菜单与素材**：自定义菜单配置、素材管理。
- **消息与群发**：模板/客服消息、按分组群发、发送记录。
- **回调**：公众号消息与事件回调接入，签名校验。

## 边界

- 🧪 实验业务线：API 与表结构可能调整。
- 微信侧的账号资质、接口权限与配额由微信公众平台侧决定，仓库不代管。
