# 通知中心

**notify 服务**统一站内信与多渠道通知：消息、模板、渠道与投递日志；平台内的告警与业务提醒都汇聚到这里。

## 能力清单

- **站内信**：消息列表 / 未读计数 / 已读，按用户与租户隔离。
- **模板**：模板码制（如 `login_alert`），支持变量与多语言文案；控制台可维护。
- **渠道**：邮件 / 短信 / 企业微信 webhook 等可插拔；渠道失败可降级为站内信兜底。
- **投递日志**：非收件箱渠道（邮件/短信）逐条留痕（状态、目标、错误详情）。
- **内部发送契约**：服务间调用受 `NOTIFY_INTERNAL_TOKEN` 门控，空值即禁用（fail closed）。

## 典型链路

- **异常登录告警**：audit 服务检测到新 IP / 新设备登录 → 认证的 notify 客户端发送 `login_alert` 站内信（默认开启，可在安全策略中关闭）。
- **监控告警**：Prometheus 规则 → Alertmanager 分组去抖 → notify webhook 站内信。

## 边界

- 外部渠道（短信/邮件服务商）凭据需用户自行配置；未配置渠道按降级策略处理。
