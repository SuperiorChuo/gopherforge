# AI 可见度

**visibility 服务**跟踪品牌在 AI 搜索与回答中的可见度：关键词、SERP 检查与趋势看板。

## 能力清单

- **总览**：可见度得分、覆盖品牌/关键词概览、历史趋势。
- **品牌与关键词**：品牌档案、关键词库、检查计划。
- **SERP 检查**：搜索结果页抓取与检查记录（checks）、历史对比。
- **看板**：按品牌/关键词/时段的可视化与导出。
- **数据范围**：租户隔离，按角色授权（`visibility:*` 权限点）。

## 边界

- 🧪 实验业务线：API 与表结构可能调整。
- 检查目标站点/搜索源的可达性与配额受外部环境影响；外部数据源凭据需自行配置。
