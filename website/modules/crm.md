# 销售 CRM

**crm 服务**覆盖线索到回款的销售链路：线索 / 客户 / 联系人 / 商机 / 合同 / 回款，与 IM 名片、呼叫通讯录双向联动。

## 能力清单

- **线索**：线索录入、查重与合并（merge）、分配与领取、转化（converted）；分配日志留痕。
- **客户与商机**：客户档案、联系人、商机阶段推进；合同与回款登记，回款与 BPM 合同审批联动。
- **公海与规则**：线索池 / 公海领取回收、分配规则（轮询等）、超时回收策略。
- **数据范围**：`my-scope` 个人 / 部门 / 全部三档；组织（org）维度过滤；跨租户强隔离。
- **列表完整性**：明细、投影与聚合列表均按完整结果集读取（分批快照），不用硬上限截断。

## 边界

- 🧪 实验业务线：API 与表结构可能调整；生产采用前请单独评估。
- 与 IM / 呼叫的联动依赖对应业务线的部署与配置。
