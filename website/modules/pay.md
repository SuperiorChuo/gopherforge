# 支付中心

**pay 服务**提供订单、收银台、退款、回调与统计的完整业务闭环。

## ⚠️ 能力边界（请先阅读）

**当前版本只提供 mock 支付渠道**，用于隔离测试与演示（`PAY_DEMO_MODE` 显式开启；生产默认关闭）。**微信支付 / 支付宝适配器尚未实现**——即使配置了真实商户凭据，也不能获得真实收款能力。模拟支付端点会让拿到收银台链接的人把订单标记为已支付，生产环境必须保持默认关闭。

## 能力清单（mock 渠道下同样成立）

- **订单**：内部建单、幂等键防重复、订单状态机（待支付 / 已支付 / 已关闭）。
- **收银台**：匿名访问的支付页（受控），mock 渠道完成模拟支付。
- **回调**：回调验签、重复通知幂等处理（重复通知返回 200 且不重复入账）。
- **退款**：部分 / 全额退款、超退拒绝、已关闭订单拒绝退款；终态锁定。
- **统计**：订单与金额汇总。
- **鉴权**：回调 token（`PAY_CALLBACK_TOKEN`）与内部 token 门控，坏 token 401。

## 路线

微信 / 支付宝等真实渠道适配器**未包含在本版本**，属于后续能力；接入前请勿基于「配置商户凭据即可收款」做计划。
