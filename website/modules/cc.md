# 呼叫中心

**cc 服务**（呼叫中台）与 `freeswitch-cc/`（FreeSWITCH 媒体 + control-api）组成呼叫中心：中台下指令、媒体面执行，事件经 HMAC 回传。

## 能力清单

- **架构**：中台 `cc` 服务经 HTTP 控制 FreeSWITCH control-api；媒体进程独立 compose，便于单独升级；事件回传带 HMAC 签名。
- **坐席与队列**：坐席/技能组、队列策略（ring-all 等）、示例队列与压测脚本。
- **黑名单与通讯录**：号码黑名单、通讯录查找并联动 CRM（`lookup has_crm`）。
- **报表**：总量 / 接听量 / 接听率 / 坐席排行榜、费率（前缀费率表）。
- **媒体**：SIP 与浏览器 WSS 话路、录音与媒体文件管理（独立媒体组件）。

## 配置依赖

- 中台控制面依赖 **`CC_FS_API_BASE`** 指向 control-api；未配置时呼叫状态/队列/报表等验收无法到达（fail closed，不伪造数据）。
- 媒体面（FreeSWITCH、SIP 中继、电话媒体）需独立部署与运营商侧配置，仓库不携带。

## 边界

- 🧪 实验业务线：API 与表结构可能调整。
- 真实电话媒体/中继、外部运营商准入不在仓库范围内；完整验收以部署侧提供 `CC_FS_API_BASE` 与媒体环境为前提。
