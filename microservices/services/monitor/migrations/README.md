# 迁移目录说明

统一迁移目录：全部基础服务与业务服务的 goose 迁移都放这里，由 compose 的
`migrate` 一次性 job 按编号顺序执行（`docker-compose.yml` 的 migrate 服务）。

## 领号规则

- 新迁移取当前最大编号 +1；**创建前先 `ls | sort` 重查一次最大号**——并行
  会话同时开发时撞号是真实风险（000051-000055 曾三方连环撞号改名）。
- goose 只要求版本号单调递增，不要求连续。
