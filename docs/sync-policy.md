# 公开范围与同步策略

从 v0.8.0 起，本仓库交付 **GopherForge 完整产品**。旧版仅同步基础脚手架、排除业务模块的政策已被本页取代；具体功能边界见[产品说明](PRODUCT_LINES.md)。

## 公开范围

- `microservices/`：16 个 API 服务、ai-service 内嵌 worker、共享库及完整 React 管理台。
- `clients/`：Hermes 管理客户端。
- `freeswitch-cc/`：独立部署的 FreeSWITCH 媒体栈与 control-api。
- `platform/`：可观测配置；另包含明确审查的构建工具、测试、工作流与产品文档。
- AI、CRM、IM、支付、公众号、通知、工单、呼叫中心和可视化业务均在产品范围内。包含代码不代表外部供应商已配置或链路已通过生产验收。

## 同步与发行

- 按固定源码对象和明确范围生成公开快照，不导入非公开维护历史、个人开发环境、维护专用规范、资料或凭据。
- 每个公开候选都检查内容、待发布历史、迁移身份和构建来源；最终验证、镜像与 Release 绑定同一个公开提交完整 SHA。
- 全仓 53 份已公开历史 SQL 保持原路径与字节；新增迁移只能向前追加，不能覆盖历史脚本，也不能在生产使用 down/reset。
- 升级前备份并在隔离的带数据副本演练；数据库恢复与应用版本须相互匹配，不把切换旧镜像等同数据库回滚。
- 批次变更记在 `CHANGELOG.md`。源码、镜像、Release 与文档站各有自己的发布状态；本地检查通过不等于已公开发布。

Issue / PR 可覆盖上述完整产品的缺陷、工程化和文档问题；新功能须单独评审，发行收敛期间不追加功能。
